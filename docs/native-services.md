# 原生校园服务

目前提供第一阶段适配，功能仍未与五个原站完整对齐。完整验收需要按登录账号逐项核对原站菜单、子页面、查询、表单、附件及提交后的结果。下表记录当前实现范围，网页跳转项仍属于待补齐的原生功能。

服务大厅的“原生服务”卡片和页面支持左右滑动切换。原学校应用图标、收藏及链接继续打开学校原站。原生入口集中在此处，避免在个人页和成绩页重复设置。

| 服务 | 原生能力 | 继续由学校页面完成 |
| --- | --- | --- |
| 教务 | 成绩、课表入口，校历、个人培养方案多级思维导图、课组要求与课程分页，已同步课程的分组与筛选 | 选课、考试报名等写入业务 |
| 缴费 | 校园卡和网费余额、用量、宿舍电量查询、本月校园卡流水；学校当前页面的缴费项目、订单表格、查询字段与操作核对 | 学校认证、支付渠道、支付结果与学校自定义控件 |
| WebVPN | 校园可达性、会话状态、认证更新入口、学校资源搜索 | 学校 WebVPN 认证和受保护网页；不提供系统级 VPN |
| 办事 | 原站动态服务目录与筛选、完整指南、流程图、材料入口和在办事项；学校当前表单的文本、多行、日期、下拉、单选、复选及操作核对 | 学校认证、附件上传、复杂动态控件、学校办理结果与后续审批 |
| 邮箱 | 文件夹未读数、列表与分页、文字阅读、主题/发件人/收件人/未读/附件/星标组合搜索，批量已读、星标与文件夹移动；新信/回复/回复全部/转发衔接学校写信窗口，附件下载管理 | 登录认证、富文本编辑、实际发送、通讯录、规则及邮箱设置；可选择系统邮件写信 |

缴费页展示已接入的校园账户数据，不能据此推断学宿费是否欠缴。接口没有返回进度、未读状态或余额时显示未读取/未知，不用 0 冒充。

表单与订单视图读取已登录 WKWebView 的实际 DOM，并保留学校原表单、隐藏字段和页面事件。原生编辑支持转回原网页继续填写。操作前展示表单内容及对应订单上下文，复核文档、字段、隐藏字段与订单内容，再触发一次对应的学校控件。结果以学校返回页面为准。文件上传、富文本和动态表单扩展仍需使用网页控件。当前读取每表前 200 行，并显示截断提示，可继续通过学校分页读取。

邮箱通过独立脚本世界调用学校客户端同源接口，包括 `user:getAttrs`、`mbox:listMessages`、`getAllFolders`、`searchMessages`、`readMessage.jsp`、`mbox:updateMessageInfos` 与写信初始化 `compose.jsp`。协议依据学校公开部署的 `coremail/bundle/{ $,X,M,C }.157e8.js` 客户端实现核对。已读、星标与移动操作在写入前后复核邮箱身份，网络中断时提示先刷新核对。首次邮箱地址不匹配校园学号时要求用户确认关联。回复和转发先取得学校创建的写信标识，再打开对应编辑窗口。实际发送由用户在学校编辑窗口完成。正文显示解码后的文字，附件由原学校页面通过 WebKit 下载管理保存。

登录按校园账号和服务隔离，使用 WKWebsiteDataStore 与 Keychain；注销清除对应会话并轮换 WebKit 配置。身份切换、页面跳转、账号代次改变时丢弃旧请求。学校会话过期仍需正常认证，不能保证永久免登录。邮箱列表不另行写入磁盘缓存。

iOS 26 的 Liquid Glass 用在切换导航控件，数据内容保持清晰的系统分组背景；减少透明度与增强对比度时提供不透明样式。使用系统动态字体、VoiceOver 标签和至少 44pt 的切换目标，不自动轮播。

Nightly 图片来自同次构建的实际模拟器页面，使用仅存在于临时 Debug 副本的合成数据，不表示真实校园账号联调或实体 iPhone 验证。

2026-11-13 的连接检查中，WebVPN 入口返回 HTTP 403，缴费和申请详情跳转学校认证。五项服务的完整网页功能对齐仍待真实账号核验，尤其是多步申请、动态联动字段、材料上传、订单分页与支付结果、富文本发送、通讯录及邮箱设置。离线协议回归与模拟器合成表单检查分别覆盖接口编码、身份隔离、必填校验、订单内容变化、一次操作限制与返回网页继续填写。

设计依据：[Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Liquid Glass](https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views)、[Live Activities](https://developer.apple.com/design/human-interface-guidelines/live-activities)。

2026-11-14 补齐缴费项目中心与订单中心入口。缴费服务使用公网缴费站点及其正常 CAS 跳转。原生页面支持学校 `onclick` 项目入口，并在异步加载后更新列表。认证、验证码、二维码和 canvas 页面保留可见原网页。后台观察内容变化时保留正在编辑的表单与操作核对状态。
