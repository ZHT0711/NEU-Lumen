# 原生教务查询

入口：服务大厅 → 展开 **原生服务** → **学业查询**。沿用当前校园账号的正常认证，按账号和会话隔离；不会自动使用演示结果代替学校响应。

## 可以读取什么

- **全部教务功能**：根据官方 `api/home/menus.do?userType=...` 的完整授权树生成栏目、搜索和功能入口，包含当前角色可见的选课、考试、学籍、培养、评教及其他业务，不用静态四个入口代表完整教务。菜单由当前身份返回，读取前后复核学号；站内模块沿用学校的 `appName/menuCode` 路由，学校外部入口保留原地址和端口。
- **考试安排**：按学校学期读取 `api/home/student/exams.do?termCode=...`，原生展示 `courseDesc/examDate/examTimeDescription/examPlace/examSeatNo/teachers` 等已提供字段。具体开始时间按上海时区解析；缺失时间不补值，也不据此安排通知。

- **校历**：官方学期列表、已提供的学期起止日期、假期日期区间，以及按日期查询的教学周。个人学期校准不会被查询自动覆盖。
- **个人培养方案查询**：与学校“培养 → 培养方案查询 → 查看详情”对应。读取 `pyfagl` 的个人方案、完整平台和课组层级，展示最低学分、至少完成课组数、必过、继承与引用标记。详情为可缩放、横纵拖动、展开收起与搜索的原生思维导图，点击节点分页读取对应课程。
- **已同步的课程表**：保留已有按账号与方案保存的课程表，以及首页学业进度查询。
- **课程明细**：在独立教务窗口正常登录、打开课程表后，主动点击「同步当前课程表」。识别已渲染表格的实际表头与行，保留课程、代码、学分原文、模块、状态及建议学期。

未返回的日期、时长、学分和课程不补零，不从学业树动画值推算学分，也不自行宣布毕业资格。完整图片校历、特殊专业权限或暂不支持的字段仍可在官方网页查看。

## 网页同步边界

同步为只读导入：临时 WebView 不持久化 Cookie，只单向接收当前 App 会话；前后使用独立 JavaScript content world 核对官方当前用户，回写时再核对 App 账号和会话时期。账号不符、换号或识别失败时保留上一份快照，不吸收网页新账号的 Cookie。

只导入当前已渲染的可识别 table / ARIA grid，同源可见 iframe 有数量与深度限制。不会自动翻页、展开隐藏内容或查询未核实接口；分页未加载行、跨源 iframe、图片、PDF、未知 div 布局暂不支持。同步时由用户明确选择保存的方案；同一方案可逐页合并课程，按账号与方案分别保存在本机，支持模块 / 学期 / 性质分组、状态筛选、课程搜索和详情查看。未知状态和缺失学分保持未知，不把已同步的部分课程当作完整培养要求。可清除本机明细后重新同步。

## 验证与数据

业务页的原生视图读取学校页面实际控件和 HTML / ARIA 表格，支持条件编辑、查询、分页控件、表单核对和单次触发学校按钮，包括 `input[type=button/submit]`。选课、报名、评教及申请等写操作仍由原学校处理逻辑执行，应用不猜测或绕过业务校验。复杂选择器、文件上传、跨域嵌入、图像/PDF 及不支持的控件可在同一已登录原页面继续；这部分不宣称已全部原生化。完整原站功能对齐仍需当前账号逐页办理验证。

协议来自公开官方教务首页脚本与已确认只读 GET 接口。仓库截图使用显式合成数据，实际运行于 iPhone 模拟器，非真实账号、非实体真机验证。特殊权限仍需使用者正常登录后检查；不要将个人截图或凭据上传至仓库。

## 培养方案详情协议

详情协议在 2026-11-14 对照学校当前 `sys/pyfagl/modules/pyfacxcd/pyfacxcd.js`、`modules/pyfagl/pyfaxzbj/pyfaxzbj.js`、`public/commonpage_PYFAGL/jsmindFrame/jsmindFrameBS.js` 与 `jsmindSidebar/jsmindSidebar.js` 核对。方案列表为 `pyfacdxxcx`，方案基本信息为 `cxpyfa`，课组层级为 `pyfakzcx`，节点课程为 `pyfakzkccxx`。使用原客户端的表单查询语义读取，支持 `pageNumber` / `pageSize` 分页。方案编号来自当前账号可查询列表，树使用 `KZH` / `FKZH` 的原始父子关系。详情图的课组要求来自 `ZSXDXF` / `ZSWCKZS`，课程学分与要求分开展示。读取前后核对当前学号，重复节点、循环、缺失父节点和跨方案响应会报错。当前课程修读状态未由该接口提供，保留未知。

桌面浏览器中已确认实际学校菜单和详情入口。个人账号接口的完整联调、继承课组权限与实体 iPhone 操作仍需登录状态下核验。模拟器图使用独立合成方案和课组，不使用个人培养方案制作公开截图。

## 联动条件与空闲教室

教务业务入口共用的原生页面现在识别学校已渲染的原生下拉、多选节次、日期、单选与复选，以及 EMAP/jqx、ARIA/Ant、Element 下拉控件。自定义下拉由用户明确展开，只展示当前学校页面实际提供且可用的选项，选择时调用原控件事件；校区、教学楼等条件逐项回写并重读联动结果。学校异步更新后继续观察，按当前页面字段保留尚未提交的文字草稿。查询与分页完成后留在原生页面读取结果；选课、报名、申请等业务操作继续核对后单次触发学校控件。

回归使用真实 WebKit 中的合成空闲教室表单，覆盖校区与楼栋联动、日期、多节次、学校自定义下拉、禁用与伪造选项、一次操作和结果表格；另在 Chromium 执行同一桥验证。此覆盖不代表已用真实账号逐项办理所有权限业务。跨域内容、未渲染的远程选项、文件上传和学校特殊控件仍提供同会话原网页继续入口。

2026-11-14 在已登录的学校网页只读核对了当前 `kxjas/kxjscxxs` 空闲教室入口、勾选式校区和楼栋条件、学校限制为当天的空闲日期、开始与结束节次、查询结果与翻页。原生桥据此补齐 EMAP `data-caption` 标签、下拉查找和完成选择事件、委托式搜索按钮，以及 jqxGrid 分离表头、图标分页和页码跳转。学校页面本身的校区关闭联动脚本目前可出现字段键不匹配错误；应用继续展示学校当前实际提供的选项和返回结果，不伪造校区与教学楼对应关系。合成回归使用相同控件结构，不包含该账号的查询截图或个人数据；实体 iPhone 与账号逐页原生操作仍需核验。
