# 首页矢量线稿

首页以 SwiftUI Shape 原生绘制校园建筑和地面轮廓，使用东大蓝低透明度描边。

浑南组景以一号教学楼为中心，信息学馆与建筑学馆分别在两侧沿同一地面展开。建筑外观参考学校发布的校园照片，保留一号楼折面砖墙和花格墙、信息学馆水平玻璃带，以及建筑学馆架空体量和不规则窗格。背景构图中的建筑位置为视觉编排。
